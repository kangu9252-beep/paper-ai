# 논문 AI

내 컴퓨터의 로컬 AI(Ollama)로 돌아가는 논문 작성 도우미. 모든 문장에 근거(저자, 연도)가 붙고, 누르면 원문 PDF의 해당 위치가 형광펜으로 보인다.

## 켜기
바탕화면 **논문 AI** 아이콘 (또는 `start.bat`) → 브라우저에서 http://127.0.0.1:8765 이 열림.
검은 창을 닫으면 꺼진다. Ollama가 켜져 있어야 한다.

## 흐름
1. **연구계획**: 주제 입력 → OpenAlex(공개 학술 색인)에서 선행연구 조사 → 연구 경로 3가지 + 추천
2. **자료수집**: 경로 승인 → 무료 공개 PDF 자동 다운로드 (설정에서 도서관을 연결하면 구독 논문도 시도)
3. **집필**: AI가 장별로 작성. 문장마다 근거 문장을 검색 모델로 찾고, AI가 과장 여부를 검증. 통과 못 하면 `?`
4. 직접 쓴 `(이기태, 2026)`은 자동으로 인용으로 인식 → 옆에 "출처 필요" 메모 → **직접 찾기** / **자동**
   - 자동: 내 PC의 해당 저자 논문 → 없으면 인터넷에서 찾아 다운로드 → 근거 위치 연결

## 원고 보강 (④ 원고 점검 탭)
이미 쓴 원고(.docx · .hwpx · .txt · 붙여넣기)를 불러와서:
- ② 인용 전체 점검 — ✔ 근거 확인 / ⚠ 원문과 다름 / ? 근거 없음
- ③ 근거 없는 문장 — 인용 없는 주장에 '출처 필요' + 내 자료에서 추천 근거 (방법·결과 장 제외)
- ④ 논의 보강 — 결과 장의 핵심 결과 ↔ 일치/상반 선행연구 + 논의 문장 제안
- ⑤ 최신 연구 — 최근 3년 관련 논문 중 원고에 없는 것 + 쓸 위치
- ⑥ 참고문헌 대조 — 목록에 없는 인용 / 연도 불일치 / 안 쓰인 문헌
인식하는 인용 형식: (저자, 2020) · (저자, 2020; 저자2 외, 2019) · (Smith, 2019, p. 3) · 저자(2020) · Neff et al.(2003)

## AI 엔진 · 새벽 작업
- 설정에서 로컬 AI / Claude 선택. Claude는 연구계획·집필·점검만 맡고, 근거 검색은 항상 로컬(bge-m3).
- 프로젝트별 '로컬 AI만 사용' (민감한 원고).
- 🌙 새벽 예약: 자료수집·집필·원고 검토를 02:00~07:00에 로컬 AI로 실행.
  설정 → '새벽 자동 실행 등록' = Windows 예약 작업 PaperAI-Night (01:55, 절전 해제, 끝나면 자동 종료, 기록은 data/night.log).

## 구조
- `server.py` 웹 서버(FastAPI) · `static/` 화면
- `core/agent.py` 계획·수집·집필·근거찾기 · `core/pdfindex.py` PDF 색인(줄 좌표까지 저장)·검색
- `core/review.py` 원고 보강 6기능 · `core/night.py` 새벽 예약
- `core/web.py` OpenAlex·다운로드 · `core/library.py` 도서관 로그인(Playwright, 크롬/엣지)
- `data/` 데이터베이스·내려받은 PDF·브라우저 프로필 (백업 대상)
