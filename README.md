# 📝 논문 AI — 모든 문장에 근거를 붙이는 논문 도우미

대학원생이 논문을 쓰고 다듬는 과정을 돕는 웹 앱입니다.
가장 중요하게 생각한 것은 **"AI가 쓴 문장이든 내가 쓴 문장이든, 근거가 원문 어디에 있는지 바로 확인할 수 있어야 한다"**는 점입니다.
인용을 누르면 원문 PDF의 해당 쪽이 열리고, 근거 문장에 형광펜이 칠해져 있습니다.

> 상담심리 대학원에서 실제로 학위논문을 쓰면서 필요한 기능을 하나씩 만들어 온 도구입니다.

---

## 왜 만들었나요?

AI로 논문을 쓰면 이런 문제가 자주 생깁니다.

- **없는 논문이나 없는 내용을 만들어 냅니다.** 그럴듯한 인용이 붙어 있지만 원문에는 그런 말이 없습니다.
- **내가 쓴 인용이 맞는지 확인하기 어렵습니다.** 인용이 70개가 넘으면 하나하나 원문을 찾아보기 힘듭니다.
- **"잘 쓴 논문"의 핵심인 일목요연함을 스스로 점검하기 어렵습니다.** 연구문제와 결론이 같은 이야기를 하는지 놓치기 쉽습니다.
- **AI를 썼다는 이유로 문제가 되는 사례가 늘고 있습니다.** AI를 어디에 썼는지 기록하고 밝힐 방법이 필요합니다.

논문 AI는 이 네 가지를 해결하는 데 집중했습니다.

---

## 주요 기능

화면은 논문 쓰는 순서대로 다섯 단계로 되어 있습니다.

| 단계 | 하는 일 |
|---|---|
| ① 연구계획 | 주제를 넣으면 공개 학술 색인(OpenAlex)에서 선행연구를 찾아 연구 경로 3가지를 제안합니다. |
| ② 자료수집 | 내 PDF를 읽어 들이고, 무료로 공개된 논문은 자동으로 내려받습니다. 사진으로 된 스캔본 PDF도 글자를 인식해 읽습니다. |
| ③ 문헌분석 | 논문마다 목적·대상·변인·방법·결과·한계를 표로 정리합니다. **표의 칸마다 원문 근거가 연결**되어 있고, 연구 공백 찾기와 서론 초안 쓰기도 할 수 있습니다. |
| ④ 집필 | AI가 장별로 초안을 쓰거나, 내가 쓴 원고를 불러옵니다. `(저자, 연도)`로 쓰면 자동으로 인용으로 인식하고 근거를 찾아 연결합니다. |
| ⑤ 원고 점검 | 아래의 점검 도구로 원고를 검토합니다. |

**⑤ 원고 점검 도구**

- **3인 모의 심사**: 예비심사처럼 심사위원 세 명이 비판점, 수정 요구, 예상 질문을 냅니다. 답변서를 쓰면 다시 심사합니다.
- **뼈대 점검**: 연구문제 → 선행연구 → 방법 → 결과 → 결론이 한 줄기로 이어지는지 봅니다.
- **인용 전체 점검**: 인용마다 ✔ 근거 확인 / ⚠ 원문과 다름 / ? 근거 없음으로 표시합니다.
- **근거 없는 문장**: 인용 없이 주장만 있는 문장을 찾아 '출처 필요'를 붙입니다.
- **참고문헌 대조**: 목록에 없는 인용, 연도가 다른 인용, 본문에서 안 쓰인 문헌을 찾습니다.
- **논의 보강·최신 연구**: 결과와 같거나 다른 선행연구, 최근 3년 안의 관련 논문을 찾아 줍니다.
- **문장 다듬기·AI 문체 점검**: 띄어쓰기, 어색한 표현, AI가 쓴 티가 나는 문장을 고칠 안을 냅니다.

**그 밖에**

- **💬 도우미**: "지금 뭘 해야 해요?"처럼 물으면 내 원고 상태를 보고 다음 할 일과 바로가기 버튼을 줍니다.
- **길잡이**: 처음 시작하는 사람 / 초안이 있는 사람 / 심사를 앞둔 사람에 맞춰 6단계로 안내합니다.
- **연구 지도·근거 저울·투고 학술지 추천·연구모형 그림**도 만들 수 있습니다.

---

## 근거는 어떻게 찾나요?

1. 원고에 `(황선환 외, 2011)`이라고 쓰면, 내 자료에서 그 저자·연도의 논문 PDF를 찾습니다.
2. AI가 그 논문을 **처음부터 끝까지 읽고** 문장을 뒷받침하는 부분을 고릅니다.
3. 고른 문장이 원문에 **글자 그대로 있는지 프로그램이 다시 확인**합니다. 확인되지 않으면 연결하지 않습니다.
4. 연결된 인용을 누르면 원문 PDF의 해당 쪽이 열리고, 근거 문장에 형광펜이 칠해져 있습니다.

못 찾으면 그대로 알려 줍니다. 예를 들어 "이 PDF를 끝까지 읽었지만 근거가 없어요. 파일이 맞는 논문인지 확인해 주세요"라고 나옵니다.
**AI가 근거를 지어내지 않도록, 원문에서 확인된 것만 연결하는 것**이 이 앱의 원칙입니다.

## AI 사용 윤리

- AI가 쓴 문단은 **보라색으로 표시**됩니다. 내가 절반 넘게 고쳐 쓰면 표시가 사라집니다.
- 어떤 기능을 언제 썼는지 **자동으로 기록**합니다.
- 기록을 바탕으로 학술지 투고용 **'AI 사용 명시' 문구를 한국어·영어로** 만들어 줍니다.

AI를 숨기지 않고, 어디에 어떻게 썼는지 밝힐 수 있게 하는 것이 목표입니다.

## 비용과 개인정보

- **AI 엔진**: Claude(Anthropic)를 씁니다. 무거운 판단(모의 심사 등)은 상위 모델, 단순한 일(PDF 저자·연도 읽기)은 가장 싼 모델에 맡겨 비용을 줄였습니다.
- **실행 전에 예상 금액**이 버튼 옆에 표시되고, **월 사용 한도**를 정할 수 있습니다. 원고가 그대로면 다시 돌리지 않고(0원), 고친 문단만 다시 점검합니다.
- 논문 한 편 기준 어림 비용: PDF 100편 읽기 약 100원, 인용 70개 근거 찾기 300~500원, 원고 전체 점검 1,000~2,000원.
- **원고와 PDF는 내 컴퓨터에 저장**됩니다. 상담 사례처럼 민감한 원고는 프로젝트마다 **'로컬 AI만 사용'**을 켜면 밖으로 보내지 않고 내 컴퓨터의 AI(Ollama)로만 처리합니다.
- API 키는 Windows 암호화(DPAPI)로 저장합니다.

## 설치와 실행 (Windows)

**필요한 것**
- Windows 10/11
- **Claude 구독(Pro 또는 Max)** — 앱이 내 컴퓨터의 Claude Code를 통해 구독으로 돌아가서 **따로 요금이 나가지 않습니다** (구독 사용량 안에서).
  구독이 없으면 Claude API 키로도 쓸 수 있지만, 쓴 만큼 요금이 나갑니다.
- 파이썬과 Claude Code는 따로 설치하지 않아도 됩니다. 처음 실행할 때 자동으로 설치합니다.
- (선택) [Ollama](https://ollama.com): 민감한 원고를 내 컴퓨터에서만 처리하고 싶을 때

**설치 (처음 한 번, 10분 안팎)**
1. [최신 버전 내려받기](https://github.com/kangu9252-beep/paper-ai/releases/latest)에서 `Source code (zip)`를 받아 압축을 풉니다.
   (또는 이 페이지 위쪽 초록색 `Code` 버튼 → `Download ZIP`)
2. 압축을 푼 폴더 안의 **`start.bat`을 더블클릭**합니다.
   - "Windows의 PC 보호" 창이 뜨면 `추가 정보` → `실행`을 누릅니다.
   - 파이썬, 필요한 프로그램, **Claude Code**를 차례로 설치합니다.
3. **Claude 로그인 창**(까만 창)이 뜨면 로그인 방식을 고르고, 브라우저에서 Claude 계정으로 로그인한 뒤 '허용'을 누릅니다. 끝나면 그 창은 닫아도 됩니다.
4. 브라우저에 앱이 열리고 **'Claude 구독으로 연결하기'** 창이 뜨면 `연결 확인`을 누릅니다. ✅가 나오면 끝입니다.

**다음부터는** `start.bat`만 더블클릭하면 바로 켜집니다. 검은 창을 닫으면 앱이 꺼집니다.
원고와 PDF는 모두 그 폴더 안의 `data` 폴더에 저장되니, 이 폴더를 지우지 마세요. 새 버전으로 바꿀 때는 `data` 폴더만 옮기면 됩니다.

## 여러 사람이 함께 쓰기

앱을 켠 컴퓨터를 웹 주소로 열어 친구들과 함께 쓸 수 있습니다.

1. [ngrok](https://ngrok.com)(무료)에 가입해 토큰을 등록한 뒤 `web-share.bat`을 실행하면, 매번 같은 `https://....ngrok-free.dev` 주소로 앱이 열립니다.
2. 친구는 그 주소에서 **초대 코드**(⚙ 설정 → 친구 초대)로 가입합니다.
3. 친구는 **자기 Claude 키**로 쓰고, **자기 원고와 PDF만** 볼 수 있습니다. 앱을 켠 사람의 폴더·설정·자료는 보이지 않습니다.

## 기술 구성

| 부분 | 사용한 것 |
|---|---|
| 서버 | Python, FastAPI |
| 화면 | HTML, CSS, JavaScript (프레임워크 없음) |
| 저장 | SQLite |
| AI | Claude API (Opus·Sonnet·Haiku를 일의 무게에 따라 나눠 씀), 선택적으로 Ollama |
| PDF | PyMuPDF (글자와 줄 위치까지 저장), Windows OCR (스캔본) |
| 의미 검색 | fastembed (앱에 들어 있는 작은 다국어 모델) |
| 학술 자료 | OpenAlex API |

**폴더 구조**
- `server.py`: 웹 서버와 모든 API
- `static/`: 화면 (`index.html`, `app.js`, `style.css`)
- `core/agent.py`: 연구계획·자료수집·집필·근거 찾기
- `core/pdfindex.py`: PDF 읽기, 검색, 근거 위치 찾기
- `core/review.py`: 원고 점검 도구
- `core/matrix.py`: 문헌분석표·연구 공백·서론
- `core/explore.py`: 도우미, 연구 지도, 근거 저울 등
- `core/llm.py`: AI 호출, 비용 계산
- `core/users.py`: 여러 사람이 쓸 때 로그인과 자료 구분
- `data/`: 데이터베이스와 PDF (저장소에는 올리지 않습니다)
